# 🚀 Node.js DevOps Portfolio Project

Учебный проект, демонстрирующий полный цикл разработки и деплоя (CI/CD) простого Node.js приложения с использованием современных DevOps-инструментов.

## 🛠 Стек технологий

- **OS:** Ubuntu 24.04 LTS
- **Scripting:** Bash
- **VCS:** Git / GitHub
- **Web Server:** Nginx
- **Containerization:** Docker / Docker Compose
- **CI/CD:** GitHub Actions (в процессе)

## 📂 Структура проекта

```text
.
├── app/           # Исходный код Node.js приложения
├── deploy/        # Конфигурации для деплоя (Nginx)

└── scripts/       # Bash-скрипты для автоматизации
